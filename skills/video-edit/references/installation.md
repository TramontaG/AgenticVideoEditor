# Portable installation

Python entry points use only the standard library until model inference. The installer finds an existing Python 3.11–3.13 automatically. With `--install-system`, if none is found, it can bootstrap a private Python 3.12 using a pinned uv distribution installed through pip. The system's default Python need not be changed. Example: `python3 scripts/setup.py install --root ~/Videos/AI-Editor --install-system --download-models`. Model and smoke commands automatically use the runtime's virtual environment.

Root resolution: `--root`, `AI_EDITOR_ROOT`, `~/.config/ai-video-editor/config.json`, then `~/Videos/AI-Editor`. The config pointer and secrets are not bundled in the skill. All paths are computed with pathlib; commands use argument arrays, not shell interpolation. Spaces in paths are supported.

`setup.py doctor` is read-only. `install` copies the bundled independent toolchain, creates `.venv`, installs local npm dependencies and Python packages, freezes Python versions, and writes an installation report. Existing lockfiles are reused. By default the installer only fills missing template files. To upgrade an existing runtime, use `setup.py install --root <runtime> --update-toolchain`: it backs up differing bundled files under `tools/template-backups/` before replacing them. Review and reapply any custom composition changes from that backup. Projects and model weights are not replaced. Source-checkout dependencies are excluded from template copying. Node dependencies are local, not global.

If Node, FFmpeg, or supported Python are absent, use `--install-system` to invoke Homebrew on macOS, apt/dnf/pacman on Linux, or winget on Windows. Commands and administrator prompts may require user interaction or environment approval. Node must be >=22; Python must be 3.11–3.13. Package repositories may offer an incompatible Python/Node version; in that case installer stops with a concrete diagnostic, rather than replacing system Python. Install a supported interpreter using python.org or the user's existing version manager, then rerun. On Windows, bootstrap with `py -3.12`; on Linux/macOS, prefer an available `python3.12`/`python3.13`.

If Python itself is missing, bootstrap before running the installer: Windows `winget install -e --id Python.Python.3.12`; macOS `brew install python@3.12`; Debian/Ubuntu `sudo apt-get install python3 python3-venv` (verify version; use an existing compatible interpreter when distro Python is newer). Do not claim a cross-platform run was tested based only on Linux validation.

Browser: Remotion's Chrome Headless Shell is downloaded inside the toolchain (`remotion browser ensure`). `AI_EDITOR_BROWSER` can select an existing compatible Chrome/Chromium. The same browser is used for headless Motion Canvas. On minimal Linux hosts Chromium can need OS shared libraries; inspect loader errors and install only the missing packages for that distribution. Do not disable browser isolation globally.

Models: faster-whisper `base` multilingual and rembg `u2netp` are small CPU-capable bootstrap models. They are real downloaded weights, not only Python packages. A larger model can be selected explicitly. CPU is default; GPU inference is enabled only after driver/runtime compatibility and an actual inference check. Do not download every available model. Model download errors and offline operation must be visible in the report. Video masks generated frame by frame need temporal QA; better matting models can be added per project without promising perfect segmentation.

Use `setup.py smoke` after installation. It creates a disposable synthetic project in runtime `projects/smoke-<timestamp>`, renders Motion Canvas, integrates its output into Remotion, runs inference on a synthetic image and audio, and saves reports. It never overwrites an existing project. Full installation is verified only after these checks pass. Render performance and model accuracy require representative real material.

Official references: [Remotion rendering](https://www.remotion.dev/docs/renderer/render-media), [Remotion licensing](https://www.remotion.dev/docs/license), [Motion Canvas rendering](https://motioncanvas.io/docs/rendering/), [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [rembg](https://github.com/danielgatis/rembg).

Transparent animation export requires an FFmpeg build with the `libvpx-vp9` encoder and decoder. The default exporter streams frames to a single VP9 WebM with alpha and validates its dimensions, frame count and alpha metadata before replacing an older video. PNG output remains optional.
